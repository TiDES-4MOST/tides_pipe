Welcome to IWG8 QXP documentation!
==================================

The 4XP is the software package used to determine the redshift of
4MOST L1 spectra for extragalactic objects by cross correllation with
a list of templates.

The development of QXP is done in the Gitlab_ repository. Bug reports
should go to Jira_.

Specifics of the file formats are described in the Data eXchange Unit
Description MST-TNO-PSC-20308-9238-0001_.
